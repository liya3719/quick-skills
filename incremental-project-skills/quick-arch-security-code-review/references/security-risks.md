# 安全审查检查项

> 在 Step 3 中加载。每条结合具体代码路径提问，不泛泛而谈。

## 注入与转义

| 项 | 自问句 |
|----|--------|
| **SQL 注入** | 用户/外部数据是否**拼接**进 SQL/ORM 原始片段？是否存在动态表名/列名？ |
| **XSS** | 未信任数据是否进入 HTML/JS/SVG/URL？模板是否默认转义？`dangerouslySetInnerHTML`/`v-html` 等是否可控？富文本白名单？ |
| **CORS** | `Access-Control-Allow-Origin: *` 与 `Allow-Credentials: true` 是否**同时**出现？反射 Origin 时是否**严格**校验白名单？ |

## 身份与权限

- 问：敏感操作前是否**再次**以服务端身份校验用户与资源归属（不只看前端隐藏）？
- 问：`userId`/`role` 是否**仅**来自**可信会话/令牌**而非请求体/Query？
- 问：是否存在**水平越权**（改 ID 看他人数据）与**垂直越权**（低权限调管理员接口）？
- 问：OAuth/Session 的 **redirect_uri、state、PKCE** 是否按规范使用？

## 敏感信息与日志

- 问：日志/错误回显/前端埋点是否包含 **Token、password、私钥、完整连接串、身份证**？
- 问：环境变量/密钥是否进入版本库、截图或**客户端**打包？

## 反序列化

- 问：是否对**用户可控**的序列化数据使用 **pickle/java 原生/ YAML load（非 safe）** 等**可执行**反序列化？
- 问：JSON 反序列化是否**类型过度信任**（如进 `Object` 再调危险方法）？

## 竞态与并发

- 问：「读-改-写」、扣库存、发券是否**无锁/无事务**在并发下重复或超额？
- 问：**TOCTOU**：鉴权/检查后到执行前，**状态**是否可能被另一请求改变？
- 问：async 中**共享可变状态**是否无同步？

## 其他高信号

- 问：文件上传：路径/后缀/内容类型是否**服务端**校验？是否**路径穿越**？
- 问：重定向/Callback URL 是否**开放**重定向？
