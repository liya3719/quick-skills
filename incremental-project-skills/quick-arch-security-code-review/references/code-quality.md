# 代码质量：错误处理与边界

> 在 Step 4 中加载。

## 错误处理

- 问：`catch` 是**空**、**仅** `console.log`、还是**吞掉**后仍继续**危险**路径？
- 问：是否把**可预期**业务错误（如余额不足）与**不可预期**系统错误**混**在一起返回给调用方/用户？
- 问：异步/Promise 链是否有**未** attach 的 rejection？
- 问：资源（文件句柄、连接、锁）在**所有**出口是否释放（含异常路径）？

## 边界条件

- 问：null/undefined/空串/0/空数组/极大值/负数时间戳 分别会怎样？
- 问：循环与分页：`limit+1` 越界、空集、**整数溢出** 是否处理？
- 问：时区/夏令时：用 UTC 还是本地？「当天」的边界按谁定义？
- 问：用户输入**长度/编码**（emoji、多字节、非法 UTF-8）是否约束？

## 可维护性信号

- 魔数、重复逻辑、**深层嵌套**（可否早返回/提取函数）?
- 命名与注释是否**撒谎**（注释说 A 行为代码做 B）？
