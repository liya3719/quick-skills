# 性能审查

> 在 Step 5 中加载。先**测量**与**热路径**再下结论，避免无依据的「优化」。

## 数据与 I/O

- 问：循环内是否有 **N+1 查询** 或未批量的单条 I/O？
- 问：是否可 **批量/分页** 却一次拉全表/全文件？
- 问：大列表渲染是否**无**虚拟化却 DOM 全挂？

## 算法与结构

- 问：热路径上是否有 **O(n²)** 可改为索引/Map **`O(1)`** 查找？
- 问：去重/计数是否用 **Set/Map** 而不用反复 `indexOf`？

## 分配与垃圾

- 问：每帧/高频循环是否 **new 大对象/大字符串拼接** 可复用或预分配？

## 前端专项（若适用）

- 问：是否**无必要**的整树重渲？memo/useMemo 是否**误**用导致缓存失效更糟？
- 问：大 JSON 是否阻塞主线程（可否流式/Worker）？

## 背压与超时

- 问：外部调用是否有 **timeout** 与**限流**，避免级联阻塞？
